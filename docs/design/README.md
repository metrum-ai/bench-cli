# Design notes

Design notes for Metrum AI Bench CLI, maintained by Metrum AI. A note records a
decision before any code exists: the question, the evidence, the options, and
a recommendation. Notes do not change behavior. Once a note's work ships, the
user docs (`docs/METRICS.md`, `docs/OUTPUT_SCHEMA.md`, `docs/CLI.md`) become
the source of truth, and the note stays as history.

| Note | Issue | Status |
|------|-------|--------|
| [AIPERF_INGEST.md](AIPERF_INGEST.md) | [#205](https://github.com/metrum-ai/bench-cli/issues/205) | Proposed: import AIPerf per-request exports, phased, after Track B |

Each new note keeps the Metrum AI copyright and SPDX header lines and links
the issue it answers.
