# Internal review artifacts

Quality and readiness assessments live here for maintainers. They are
**excluded from the crates.io package** (`Cargo.toml` `exclude`).

Hostnames, home-directory paths, and secret-shaped strings from prior
reviews are scrubbed. Full history rewrite of already-published tags is a
separate operation.
