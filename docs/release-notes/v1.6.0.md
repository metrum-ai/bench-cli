# v1.6.0: security update

Metrum AI Bench CLI v1.6.0 is a security update release that also adds CLI
flags and features. Security comes first: two weekly-scan backlogs (W43,
W44) are fully remediated, including a RustSec advisory batch on the bundled
zstd crate.

## Security fixes

| Issue | PR | Advisory / finding |
|-------|----|--------------------|
| #291 | #317 | Release workflow `secrets: inherit` replaced with the single `HF_TOKEN` mapping (least-privilege reusable workflow) |
| #292 | #318 | Self-hosted runner image runs as non-root (`RUN_AS_ROOT=false`, runner-owned `/opt/rust` toolchain, runner-listener `HEALTHCHECK` — also closes #339) |
| #293 | #319 | Dependabot seven-day cooldowns on routine updates in cargo, gomod and github-actions (security updates never delayed) |

## Features

- `--ci-safety` agent/CI preset (#303/#323): implies `--fail-on-error` +
  `--fail-on-partial`; all-error, endpoint-down and interrupted runs exit
  non-zero.
- URL validation before traffic (#304/#320): scheme-less or non-http `--url`
  values exit 2 before any request; opt-in `--validate-model` preflight
  checks the model against `/v1/models`; credentials in echoed URLs are
  redacted.
- `--data-log-mode` output collision policy (#305/#321): `append` (default),
  `refuse-existing` (atomic O_EXCL, exit 2), `overwrite`, `new-dir`.
- Standalone `--version-only` on llm/vlm/imagegen (#307/#322): prints the
  version and exits 0 without demanding run arguments.
- Streaming NDJSON request rows (#310/#324): tagged rows are emitted as
  requests complete (concurrent record consumer + 250 ms writer flush).
- Synchronous telemetry boundary sample (#312/#325): every configured source
  is scraped once immediately before the first measured request, tagged
  `boundary: "pre-measured"`; per-request queue-sample freshness stamps.
- Ready all-smi + vLLM telemetry preset (#311/#326):
  `examples/telemetry/all-smi-vllm.yaml` and a 4-node variant.
- Strict SUT publication profile `--sut-profile strict` (#308/#327):
  requires exact model revision, quantization, KV dtype, operator-declared
  kernel/graph evidence and a linked quality-evidence artifact.
- `endpoints-export` subcommand (#306/#329): converts a run data log into an
  Endpoints-shaped, explicitly non-certifying bundle with crosscheck
  arithmetic and a NONCOMPLIANCE.md.
- `--arrival burst` (#309/#330): native Offline-style population burst —
  every request at t=0, optional `--max-concurrency` cap, fd-budget guard,
  full tail drain in the measured window.
- Prompt-sequence comparability (#313/#331): `--prompt-sequence-log` /
  `--prompt-sequence` fingerprint replay, `--start-jitter-ms`, bounded
  `--sse-trace-first-n`, and `ttft_first_any_s` for reasoning models.

## Validation

Validated on NVIDIA RTX PRO 6000 Blackwell SE: v1.6.0 vs v1.5.4 within 0.7%
(output tok/s) across 12 points, BF16 + NVFP4 · Qwen3.8-27B · vLLM 0.32.0.
The A/B was run on the 2026-10-26 integration build carrying the same
feature PRs, before the final W44 dependency/test fixes and conflict
resolutions were merged.
