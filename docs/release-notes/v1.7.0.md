# v1.7.0

Metrum AI Bench CLI v1.7.0 adds a standard performance-validation harness
(#333) and includes security fixes for endpoint credential redaction (#332)
and an external-docs dependency (#341).

## Behaviour changes

- `--extra-body-json` null values remove top-level keys; non-object extra
  bodies now error (#357).
- Prompt selection searches bounded joint-length compositions for mixed
  medians and writes diagnostic reports on selection failure (#358).
- Strategic CSV exports retain a cell for absent TTFT provenance, including
  failed requests; the JSON summary is printed before exports (#362).

## Validation

The live-modality gate and performance A/B are required before release.
See the release PR for evidence and cost.

## Data points

The schema-derived counts are 55 summary quantities (340 values), 62 strategic
sweep-point quantities (367 values), 25 `request.v3` numeric fields and 12
`telemetry.v1` request-row numeric fields. Telemetry series are selected at
runtime and have no fixed count. See [DATA_POINTS.md](../DATA_POINTS.md).
