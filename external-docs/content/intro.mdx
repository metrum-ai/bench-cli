# Metrum AI Bench CLI Documentation

Metrum AI Bench CLI is Apache-2.0 licensed load and performance measurement for
OpenAI-compatible LLM, VLM, ASR, and image-generation endpoints. One client
process measures one environment and writes a result with a manifest.

Metrum AI Bench Platform (commercial) remembers, compares, governs, and
attests. This documentation covers the open-source CLI only.

Current release: **1.0.0**.

## Getting started

New to Metrum AI Bench CLI? Start here.

- [Quickstart](./docs/quickstart.mdx): install the CLI and complete a local
  dummy-server run in a few minutes.
